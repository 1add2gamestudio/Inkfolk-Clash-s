04. Technical Support & FAQ

技术支持与常见问题

关于游戏存档、CG 成就条件、APK 安装或 Bug 反馈，均可通过下方说明与支持表单联系 1add2 Game Studio。

如何解锁全部 6 幅战史 CG 并领取金币？

每张 CG 对应特定战况（例如单局出动 10+ 精锐取胜、Age III+ 凯旋、敌城残血 ≤35% 惜败等）。解锁后在主界面点击 Awards 进入成就馆即可大图欣赏并领取金币赏金。

安卓版 APK 如何下载与安装？

前往 GitHub Releases 的 latest-apk 页面下载编号最新的 debug APK，安装时允许“未知来源应用”即可体验完整版（含全部 6 张高清 CG）。

游戏是否会收集我的个人隐私数据？

不会。游戏默认采用本地离线存档保存进度，不要求注册账号，不采集姓名、手机号或位置信息。详情可查阅页脚的 Privacy Policy。

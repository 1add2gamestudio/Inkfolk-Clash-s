   - 《Inkfolk Clash》高度重视玩家隐私。游戏默认以本地离线存档（`localStorage`）保存关卡进度、金币、时代等级与 CG 成就解锁状态，**不强制要求账号注册，不收集姓名、手机号、通讯录或精确地理位置**。
2. **第三方服务与广告（Advertising & Analytics）**：
   - 免费版本可能接入合规移动广告 SDK（用于玩家主动点击触发的战后双倍奖励或章节间插屏广告）。若玩家购买 **No-Ads Pass（永久去广告通行证）**，将永久关闭全部广告展示与广告请求。
   - 若未来接入崩溃日志或匿名统计，仅用于修复闪退与平衡关卡难度，不与个人身份关联。
3. **儿童隐私保护（Children's Privacy）**：
   - 我们不会有意收集 13 岁以下儿童的个人身份信息。如监护人发现相关情况，请通过下方支持邮箱联系我们立即删除。
4. **本地数据删除方式（Data Deletion）**：
   - 玩家可随时在游戏内 `Settings → Reset Save Data` 一键清空全部本地存档，或卸载应用彻底移除数据。

## 6. 技术支持页文案框架（Support URL Framework — 官网已内置对应区域）

> **URL 示例：** `https://1add2gamestudio.github.io/Inkfolk-Clash-s/#support`

- **常见问题（FAQ）**：
  1. **如何解锁全部 6 张战史 CG？** 每张胜利/战败 CG 均有明确战况条件（如单局出动 10+ 精锐取胜、Age III+ 凯旋、敌城残血 ≤35% 惜败等），可在主界面 `Awards X/6` 查看条件并领取金币赏金。
  2. **游戏进度存在哪里？** 当前版本保存在设备本地存储，请勿随意清除浏览器缓存或应用数据。
  3. **卡关了怎么办？** 可在局内优先升级 `Food Lv.` 提升粮草产速，攒粮草一波齐放骑士+穿云弓，或在战败后使用补给强化重试。
  4. **如何关闭震动或音效？** 点击主界面右上角齿轮图标（Settings）即可分别开关 Sound Effects 与 Haptics。

  - 客服与 Bug 反馈邮箱：`support@1add2gamestudio.com`
  - GitHub Issue 反馈：`https://github.com/1add2gamestudio/Inkfolk-Clash-s/issues`
